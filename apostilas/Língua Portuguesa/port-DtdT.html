Pronomes Relativos

1. O Que São Pronomes Relativos?

Imagine que você está escrevendo e usa a mesma palavra várias vezes seguidas. Fica um pouco repetitivo, certo? Veja este exemplo:

  • Eu tenho um gato.
  • O gato gosta de dormir.

A palavra "gato" apareceu duas vezes. Os Pronomes Relativos servem para evitar essa repetição e, ao mesmo tempo, conectar as duas frases, transformando-as em uma só.

Um Pronome Relativo é uma palavra que liga duas partes de uma frase (chamadas orações) e substitui um termo que já foi mencionado antes, tornando a frase mais fluida e clara.

Usando um pronome relativo, nossas frases de exemplo ficariam assim:

Eu tenho um gato que gosta de dormir.

Aqui, "que" substitui "o gato" e conecta as duas ideias.

2. Quais São e Como Usar os Pronomes Relativos? 📝

Existem vários pronomes relativos, e cada um tem seu uso específico. Vamos conhecer os mais importantes:

2.1. QUE (o "coringa"!)

O QUE é o pronome mais usado! Ele pode se referir a quase tudo:

  • Pessoas (A menina que canta é talentosa.)
  • Coisas (Comprei o livro que você indicou.)
  • Animais (O cachorro que late muito é meu.)
  • Lugares (A cidade que visitamos é linda.)

Ele é invariável, ou seja, não muda (não tem "quês", "quás", etc.). É sempre "que".

Exemplos com QUE:

  • Este é o filme que mais gosto.
  • As ideias que me inspiram são fantásticas.

👉 Lembre-se: O QUE sempre retoma um termo que veio antes na frase!

2.2. QUEM (só para pessoas!)

O QUEM é usado apenas para pessoas. Ele geralmente aparece com uma preposição antes (a, com, de, em, para, por, etc.).

Exemplos com QUEM:

  • Este é o amigo com quem viajei. (Viajei COM alguém)
  • As pessoas a quem ele se referiu estão aqui. (Ele se referiu A alguém)

👉 Não use "quem" para coisas ou animais! É um erro comum.

2.3. ONDE (só para lugares!)

O ONDE serve exclusivamente para indicar lugar. Você pode, muitas vezes, substituí-lo por "em que".

Exemplos com ONDE:

  • Visitei a casa onde meus avós moravam. (A casa é um lugar)
  • O restaurante onde almoçamos é famoso. (O restaurante é um lugar)

👉 Se o verbo da frase indicar movimento para um lugar (ir, chegar, voltar), use "AONDE". Ex: "A cidade aonde você vai é bonita."

2.4. CUJO(A)(S) (indica posse!)

O CUJO(A)(S) é usado para mostrar posse (algo que pertence a alguém ou a algo). Ele concorda em gênero (masculino/feminino) e número (singular/plural) com o substantivo que vem DEPOIS dele. Atenção: nunca se usa artigo (o, a, os, as) depois de "cujo"!

Exemplos com CUJO(A)(S):

  • Este é o escritor cujo livro está na lista dos mais vendidos. (O livro é DO escritor)
  • Conheci a artista cujas pinturas são famosas. (As pinturas são DA artista)

🚫 Errado: "O escritor cujo o livro..."
✅ Certo: "O escritor cujo livro..."

2.5. QUANTO(A)(S) (só com "tudo" ou "todos"!)

O QUANTO(A)(S) só deve ser usado quando tem uma palavra como TUDO, TODO(A) ou TODOS(AS) antes dele na frase. Ele também concorda em gênero e número com essa palavra.

Exemplos com QUANTO(A)(S):

  • Fiz tudo quanto pude. ("Tudo" é singular, então "quanto" é singular)
  • Gastei todas quantas moedas tinha. ("Todas" é plural e feminino, então "quantas" é plural e feminino)

2.6. O(A) QUAL, OS(AS) QUAIS (para mais clareza!)

Estes pronomes (O QUAL, A QUAL, OS QUAIS, AS QUAIS) se referem a pessoas ou coisas e concordam em gênero e número com o termo que eles retomam. São muito úteis para:

  • Evitar que a frase tenha mais de um sentido (ambiguidade).
  • Deixar a frase mais formal ou elegante.
  • Quando há preposições mais longas (como "para", "com", "sem").

Exemplos com O(A) QUAL, OS(AS) QUAIS:

  • Comprei um novo computador, o qual é muito rápido. (Refere-se ao "computador")
  • As alunas, as quais tiraram notas altas, foram premiadas. (Refere-se às "alunas")
  • Esta é a escola na qual estudei. (Para "em a qual")

👉 Muitas vezes, você pode usar "que" no lugar de "o qual". Mas "o qual" é mais preciso.

Tabela Resumo dos Pronomes Relativos 📊

Pronome Para que serve? Observações importantes
QUE Pessoas, coisas, lugares, animais É o "coringa", invariável (não muda)
QUEM Somente para pessoas Geralmente vem com preposição antes (a, com, de, por...)
ONDE Somente para lugares Se tiver movimento, use "AONDE"
CUJO(A)(S) Indica posse (de quem?) Concorda com a palavra DEPOIS dele. NUNCA use artigo depois!

3. Na Prática: Exemplos Corretos e Incorretos 🚦

Vamos ver como é fácil usar os pronomes relativos de forma correta e quais erros são mais comuns para você não cair neles.

3.1. Uso do QUE

✅ Certo:

  • A menina que mora perto é minha amiga.
  • Este é o brinquedo que eu queria.

❌ Errado:

  • A menina quem mora perto é minha amiga. (🚫 "Quem" precisa de preposição ou de um verbo que a exija)

3.2. Uso do QUEM

✅ Certo:

  • Ele é o professor a quem todos respeitam. (Quem respeita, respeita A alguém)
  • Estas são as pessoas com quem conversei. (Conversei COM alguém)

❌ Errado:

  • Este é o filme quem vi ontem. (🚫 "Quem" não se usa para coisas)
  • O gato quem fugiu voltou. (🚫 "Quem" não se usa para animais)

3.3. Uso do ONDE

✅ Certo:

  • A praça onde brincávamos está reformada. (A praça é um lugar)
  • A escola aonde vamos é nova. (Ir A algum lugar)

❌ Errado:

  • A situação onde vivemos é complicada. (🚫 "Onde" não se usa para "situação", use "em que")
  • O problema onde pensamos é complexo. (🚫 "Onde" não se usa para "problema", use "em que")

3.4. Uso do CUJO(A)(S)

✅ Certo:

  • Este é o aluno cujo nome foi sorteado. (O nome é DO aluno)
  • Admiro a professora cujas aulas são muito boas. (As aulas são DA professora)

❌ Errado:

  • Este é o aluno cujo o nome foi sorteado. (🚫 Nunca use artigo depois de "cujo")
  • A menina que sua mochila sumiu está chorando. (🚫 Repetição, use "cuja")
