🚀 Aventuras Matemágicas (Função do 1º Grau) ✨

🤔 O que é essa tal de Função do 1º Grau?

Imagina que a matemática tem receitas mágicas! Uma delas é a Função do 1º Grau. Ela é como uma instrução que transforma um número (que a gente chama de x) em outro número (que a gente chama de f(x) ou y). É como uma máquina de transformar números!

Essa "receita" ou "máquina" sempre segue um formato especial, uma regra!

📜 A Receita Secreta: f(x) = ax + b

A fórmula mágica da Função do 1º Grau é sempre assim:

f(x) = ax + b

(Lê-se: "éfe de xis é igual a á xis mais bê")

Aqui, x é o número que você coloca na máquina. f(x) é o resultado que sai da máquina. Mas... quem são a e b? 🤔

Os Ajudantes Mágicos: a e b

  • Ajudante a (Coeficiente Angular): É o número que multiplica o x. Ele é muito importante porque ele diz se a linha que vamos desenhar vai subir 👍 ou descer 👎.
    • Se a for um número positivo (maior que zero, como 1, 2, 5), a linha sobe! 😊
    • Se a for um número negativo (menor que zero, como -1, -3, -10), a linha desce! 😟
    • Ah! E o a não pode ser zero, senão não é uma Função do 1º Grau!
  • Ajudante b (Coeficiente Linear): É o número que fica sozinho, sem multiplicar ninguém. Ele é o "ponto de partida"! Ele nos conta onde a nossa linha mágica vai cruzar o eixo Y (aquela linha vertical no gráfico 📈).

⭐ Exemplo Divertido ⭐

Olha essa função: f(x) = 2x + 3

  • Quem é o ajudante a? É o 2 (o número que multiplica o x). Como ele é positivo, a linha vai subir! 👍
  • Quem é o ajudante b? É o 3 (o número sozinho). Isso quer dizer que a linha vai cortar o eixo Y no número 3.

✏️ Desenhando a Linha Mágica (O Gráfico!)

A Função do 1º Grau, quando a gente desenha, vira sempre uma linha reta! Que legal, né? 😄 Essa linha pode estar inclinada, subindo ou descendo.

Quando o ajudante a é positivo (> 0), a linha sobe da esquerda para a direita! Parece um foguete decolando! 🚀

Quando o ajudante a é negativo (< 0), a linha desce da esquerda para a direita! Parece um escorregador! 🤸

E lembra do ajudante b? Ele é o número onde a linha toca no eixo Y (a linha que fica em pé).

🎯 Onde a Linha Toca o Zero (A Raiz!)

Tem um ponto super especial na nossa linha: é onde ela cruza o eixo X (a linha deitada). Esse ponto é chamado de raiz ou zero da função. É o valor de x que faz o resultado da função (f(x)) ser igual a zero!

Para encontrar esse valor mágico de x, usamos outra formulinha secreta:

x = -b / a

(Lê-se: "xis é igual a menos bê dividido por á")

⭐ Exemplo Divertido ⭐

Vamos usar a função f(x) = 2x + 4 de novo.

Lembramos que a = 2 e b = 4.

Agora usamos a fórmula da raiz:

x = -b / a x = -4 / 2 x = -2

Isso significa que a nossa linha mágica vai cortar o eixo X no número -2! ✨

8. Qual a fórmula para encontrar a raiz da função f(x) = ax + b?

10. O gráfico de uma função do 1º grau é sempre uma...

🔑 Respostas (Gabarito)

  1. b (f(x) = ax + b)
  2. a (O número que multiplica o x é 3)
  3. c (O número sozinho é 7)
  4. b (Se 'a' é positivo, a linha sobe)
  5. a (Se 'a' é negativo, a linha desce)
  6. b ('b' indica onde corta o eixo Y)
  7. c (Onde corta o eixo X é a raiz)
  8. b (x = -b / a)
  9. b (Aqui a=1 e b=-1. Raiz = -(-1)/1 = 1)
  10. b (Sempre uma linha reta!)
